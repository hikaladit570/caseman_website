# CaseMan homepage

Direction approved by the user: closely follow SMC Hospital's homepage composition, with CaseMan content and an edit panel. Light theme preserves the supplied reference's hospital identity.

ENERGY 2 / RHYTHM 3 / MOTION 2.

- Cyan navigation and green action accents echo the reference while keeping body text dark for readability.
- Two header rows, panoramic carousel, welcome panel, role links, feature sections, guide tabs and fixed quick access preserve the reference's page silhouette.
- Arial is an offline-safe humanist-adjacent sans serif option that keeps a practical hospital information page readable without external font requests.
- Larger spacing separates product introduction, operational features and reading material; compact navigation serves repeat visitors.
- Cards group independent guides; features use open rows to avoid an undifferentiated card wall.
- Clinical icons identify documented functions. The existing CaseMan mascot is reused as a project-owned identity asset.
- The banner gradient provides contrast behind text over photography. Header gradient echoes the supplied reference.
- Shadows distinguish fixed quick access and modal surfaces from page content.
- Carousel movement exposes alternative product entry points, includes pause, and reduced-motion support disables transitions.
- Original generated team image is illustrative, with its status disclosed. No invented hospital endorsements, staff identities, performance claims, or testimonials.
- Source: ../MODUL_PENGGUNAAN_CASEMAN.md and user brief. Website does not expose patient files or application configuration.
- The admin entry is placed in the footer because content management is a secondary operational action, not a visitor journey.
- The login screen uses the existing cyan and green system with a single shield motif so the protected context is clear without introducing a new visual language.
- The verified-story area uses one bordered empty state instead of testimonial-shaped placeholders because absent evidence should read as an honest state, not simulated social proof.
- Interactive controls use a minimum 44 px target; carousel indicators keep their slim visual marks inside larger invisible hit areas.
