## Added admin capability

- Footer includes a visible Login Admin control.
- `/admin` presents a responsive login screen.
- Credentials come from server environment variables.
- Sessions use a signed HTTP-only, Secure, SameSite Strict cookie with an eight-hour lifetime.
- Public content is read from Cloudflare D1 through `CONTENT_DB`.
- Authenticated saves are validated and written to D1 for all visitors.
- Database absence falls back to bundled content for public reads and returns a clear error for writes.
